# ADR-003: 流程设计两栏画布与右侧配置面板

## Status

Proposed（待确认）

## Date

2026-09-21

## Scope

- 页面：`/admin/flow/manage/deploy`
- 前端：`frontend/apps/admin/features/fa-flow-pages/`
- 本期不修改流程模型、发布接口、后端版本数据和全局主题

## Context

当前节点配置通过 Drawer 打开，会遮挡画布，节点与配置无法同时查看。流程版本不是高频操作，不放在主体区域；后续通过按钮和浮层查看历史版本。

## Decision

1. 在现有 `FaFullContentModal` 和步骤导航基础上，只调整“流程设计”步骤的内容区域。
2. 使用现有 Ant Design `Splitter` 实现“画布 + 右侧配置面板”两栏布局。右侧面板支持拖拽调整、收起和展开，画布占用剩余空间。
3. 增加统一的选中节点状态。点击节点后在右侧面板显示配置，并在画布中标记选中节点。
4. 移除节点配置 Drawer，但保留现有表单字段、校验、Store 更新逻辑和节点配置 Tab。查看 JSON 的 Drawer 保持不变。
5. 基础信息和扩展配置继续使用现有步骤，不在右侧重复创建一套流程基础表单。
6. 历史版本列表和版本查询接口留作后续版本，不在本期实现。

## 开发说明

### F-DC-01 两栏编辑器布局

- 在 `FlowProcessEdit` 的流程设计步骤内使用一个横向 `Splitter`。
- 中间面板放置现有 `FaWorkFlow`，右侧面板放置配置内容。
- 保留现有标题栏、步骤导航、发布、取消、缩放、小地图和 JSON 查看功能。

### F-DC-02 配置面板调整与收起

- 右侧面板设置合理的默认宽度和最小宽度，避免表单被压缩。
- 面板内容独立滚动，画布继续占用剩余空间。
- 收起面板后，画布自动扩展；展开后恢复配置区域。

### F-DC-03 节点选中状态

- 在现有 `useWorkFlowStore` 中增加选中节点 key 和选择/清除方法。
- 节点点击只负责选择节点，不再打开节点 Drawer。
- 删除按钮、添加节点按钮等操作需要阻止事件冒泡，避免误触发节点选择。

### F-DC-04 Drawer 迁移到右侧面板

- 将现有节点 Drawer 内的表单内容挂载到统一的右侧配置面板。
- 保留现有节点类型的基础设置、表单权限、条件配置和其他已实现配置。
- 节点名称编辑、表单变更和流程模型更新继续复用现有 Store 方法。
- 右侧面板切换节点时，表单值必须跟随当前节点刷新。

### F-DC-05 空状态与只读态

- 未选择节点时显示简洁的配置提示，不渲染无关表单。
- 只读流程可以选择和查看节点，但不能修改名称、表单或流程结构。
- 节点被删除或流程重新加载后，清理无效的选中节点状态。

### F-DC-06 页面与主题适配

- 使用项目现有布局工具和 Ant Design 主题 token，不新增全局颜色。
- 统一右侧面板标题、边框、内边距和 Tab 样式。
- 窄窗口下保证画布可用，必要时收起右侧配置面板。
- 不改动现有 `ZoomPanEditor` 的缩放和平移实现。

### F-QA-01 流程编辑交互回归

- 验证面板拖拽、收起、展开和窗口缩放。
- 验证不同节点的配置切换、实时更新、删除和新增节点。
- 验证滚轮缩放、平移、小地图、JSON 查看和主题切换不受影响。
- 验证基础信息、扩展配置、发布、取消和只读查看保持原有行为。

### F-FUTURE-01/F-FUTURE-02 历史版本

- 后续在编辑器工具栏增加“历史版本”按钮。
- 使用 Modal 或浮层展示版本列表，不占用主体画布区域。
- 先确认后端或流程引擎的版本查询能力，再设计最小查询接口。
- 历史版本默认只读，避免误修改已发布流程。

## Non-Goals

- 不增加左侧历史版本面板。
- 不在本期新增历史版本查询接口或版本切换功能。
- 不迁移到 Canvas、React Flow 或其他流程渲染框架。
- 不重做流程表单设计器，不修改后端发布流程。

## Acceptance Gates

1. 流程设计步骤显示画布和右侧配置面板，右侧面板可调整、收起和展开。
2. 点击节点后，节点有明确选中状态，右侧展示对应配置且不再打开 Drawer 遮罩。
3. 配置修改后流程节点摘要和流程模型同步更新。
4. 缩放、平移、小地图、JSON 查看、步骤切换、发布、取消和只读态无回归。
5. 亮色/暗色主题和窄窗口下布局可用。

## Implementation and Verification Record

- 2026-09-21：完成 F-DC-01 两栏编辑器布局。流程设计步骤已接入现有 Ant Design `Splitter`，右侧暂保留节点配置占位面板；节点 Drawer 迁移、节点选中状态和历史版本仍未实现。人工验证通过，状态更新为 `✅已完成`。
- 2026-09-21：完成 F-DC-02 配置面板调整与收起。复用 `Splitter` 的默认/最小/最大宽度和 `collapsible` 配置，右侧内容区增加独立纵向滚动。人工验证通过，状态更新为 `✅已完成`。
- 2026-09-21：完成 F-DC-03 节点选中状态。Store 增加选中节点 key 和清除方法，节点点击改为记录选中并增加视觉高亮；添加、删除和排序控件跳过选中事件，并修正条件分支卡片边缘命中、嵌套并行分支描边和画布平移焦点框。人工验证通过，状态更新为 `✅已完成`。现有节点表单 Drawer 迁移留给 F-DC-04。

## Risks and Rollback

- 若部分节点表单迁移后出现状态残留，优先按节点 key 重置表单实例和选中状态。
- 若右侧面板影响画布尺寸测量，先保证 Splitter 容器尺寸正确，再调整画布适配触发时机。
- 若迁移范围过大，可保留现有表单内容，仅替换 Drawer 容器为统一右侧面板宿主。
