## 目标与范围

- 从 `/admin/flow/manage/deploy` 入口优化流程编辑器，兼容表单管理内嵌编辑和只读流程展示。
- 沿用 React、Ant Design、Zustand/Immer、DOM 流程树和现有缩放画布，保持流程 JSON 与发布接口兼容。
- 优先完成可见页面和对应逻辑，再推进复杂节点；每项完成后单独人工测试。
- 按功能逐项实施，当前进度以功能清单为准。

## 功能开发说明

### F-01 节点卡片与画布升级

- 统一卡片样式，各类型使用对应图标与语义色，展示人员、审批方式、条件或时间摘要。
- 完善悬停、选中、缺配置和长文本状态；运行状态与节点类型分别表达。
- 增加低对比画布背景，统一工具栏与小地图样式，兼容亮暗主题和分支连线。
- 涉及：`NodeWrap.tsx`、`nodes/*.tsx`、`index.scss`、`hooks/useNodeCls.ts`、`cubes/ZoomPanEditor.scss`。

### F-02 配置面板与添加入口

- 固定类型、名称和页签头部，主体滚动；人员类型改为两列，审批规则按用途分组。
- 添加入口按审批、分支、自动化分类，添加后自动选中节点并展示对应配置。
- 保留已有配置入口，统一空态、说明和键盘操作；修复节点切换与输入时反复重置表单的问题。
- 涉及：`NodeConfigPanel.tsx`、`nodes/AddNode.tsx`、`nodes/property/*.tsx`、`cubes/NodeSetTypeRadio.tsx`。

### F-03 问题列表与定位

- 增加校验问题面板，点击问题定位画布节点、配置页签和字段。
- 校验结果携带节点 Key、字段路径与消息，发布使用最新配置。
- 修复“发起人自己”类型被前端校验拒绝的问题；无效 JSON 显示错误状态，避免页面崩溃。
- 涉及：`modelValidation.ts`、`NodeConfigPanel.tsx`、`FlowProcessEdit.tsx` 和画布定位逻辑。

### F-04 分支结构操作修复

- 修复分支内节点删除遗漏、分支折叠丢失汇合后续的风险，结构修改作为一次原子操作。
- 保留默认分支位置和配置上下文，默认语义与本地引擎核对后统一显示、编辑和校验。
- 中间插入结束节点时提示对后续流程的影响，避免静默截断。
- 涉及：`utils.ts`、`nodeLookup.ts`、`stores/useWorkFlowStore.ts`、分支组件与 `AddNode.tsx`。

### F-05 撤销重做与会话隔离

- 提供撤销、重做按钮和编辑器范围内的快捷键；合并连续文本输入，限制历史容量。
- 编辑器独立管理状态，画布和配置面板共享同一会话，查看器卸载不影响其他实例。
- 模型使用单一来源，保存时序列化；恢复历史时同步表单，人员查询丢弃过期响应。
- 保留步骤切换时的选择、缩放与位置，调整面板宽度时减少画布跳动。
- 涉及：`stores/useWorkFlowStore.ts`、`FaWorkFlow.tsx`、配置表单和 `FlowProcessEdit.tsx`。

### F-06 暂存与未保存保护

- 增加保存按钮及未保存、保存中、已保存、失败状态，取消或离开时提醒未保存修改。
- 使用现有 update 接口暂存，先核对其与已部署模型的关系；暂存不触发发布，发布执行完整校验。
- 本地应用表单与服务端保存使用不同提示；保存失败保留内容，保存成功但发布失败分别反馈并允许重试。
- 涉及：`FlowProcessEdit.tsx`、`services/flow/manage/flowProcess.ts`；后端仅在现有接口无法满足闭环时调整。

### F-07 表单字段驱动的条件编辑

- 从关联表单选择字段，根据类型提供值控件；条件以分行卡片展示，明确 AND/OR 关系。
- 条件、包容、路由共用编辑控件，但保留各自运行语义；业务变量保留合法的手动输入入口。
- 提示字段删除、路由目标失效等问题；操作符与值类型按本地引擎契约实现。
- 涉及：`BranchNode.tsx`、`InclusiveNode.tsx`、`RouteNode.tsx` 和表单元数据。

### F-08 字段权限与子流程配置优化

- 权限面板增加搜索和分组，保留已有批量勾选及查看、编辑、必填联动。
- 子流程复用 `FlowProcessSelect`，保存流程 Key，展示名称及同步/异步摘要。
- 配置重开可回显，旧模型和未知字段不丢失，运行效果与办理端共同验收。
- 涉及：`nodes/property/NodeFormAuth.tsx`、`nodes/CallProcess.tsx`。

### F-09、F-10 后续效率功能

- 根据长流程使用需求增加搜索、大纲和小地图开关。
- 普通节点复制先实现；跨分支复制、移动和拖拽在结构操作稳定后推进，处理 Key 和路由引用。

## 验证与进度规则

- 每项执行受影响范围的 lint、类型检查和必要定向测试，不运行全量构建。
- 人工测试覆盖部署页、内嵌编辑、只读查看、亮暗主题、缩放及对应功能闭环；复杂节点补充真实流程运行验证。
- 基线：现有模型校验、节点查找和画布坐标测试共 15 项通过；尚未覆盖上述结构风险，无浏览器或真实流程验收结果。
- 开发时更新为 `🟡进行中`；开发完成待验证更新为 `🔍验证中`；用户确认验证成功后更新为 `✅已完成`，失败需返工更新为 `🔄待返工`。
- 与 ADR-002/003/004 衔接，保留既有验收记录，不将界面可配置视为运行能力已完成。
